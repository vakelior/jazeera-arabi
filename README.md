# جزيرة عربي

موقع إخباري عربي (RTL) مستضاف على GitHub Pages.

هذا الموقع يعرض قالبًا إخباريًا بواجهة عربية كاملة، قابل للتصفح على:
https://vakelior.github.io/jazeera-arabi/

## البنية

- `index.html` — الصفحة الرئيسية (SSR)
- `static/css/` — ملفات التنسيق
- `static/js/` — ملفات الجافاسكريبت
- `static/media/` — الخطوط والشعارات
- `images/` — الصور

## النشر

يُستخدم GitHub Pages (نشر من فرع `main` — المسار `/`)، بدون أي خطوات بناء.
