# جزيرة عربي

موقع أخبار عربي (RTL) مبني بـ **React + Vite**، يعمل بالكامل على **GitHub Pages**.\n\n## ✨ المميزات\n- تصميم عربي سريع ومتجاوب (RTL)\n- أقسام: سياسة، اقتصاد، رياضة، ثقافة، تكنولوجيا، صحة\n- صفحة مقال كاملة\n- وضع ليلي (Dark Mode)\n- شريط أخبار عاجلة\n\n## 🚀 التشغيل محلياً\n```bash\nnpm install\nnpm run dev\n```\n\n## 📦 البناء\n```bash\nnpm run build\n```\n\n## 🌐 النشر\nيُنشر تلقائياً على GitHub Pages عبر GitHub Actions عند الدفع لفرع `main`.
